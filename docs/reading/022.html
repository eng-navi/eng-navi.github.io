No.22 ウェブページ問題

目安40秒。英文を読んで、AかBか選んでみよう。

WEB PAGE⏱ 目安40秒
www.oceanviewhotel.com

❶ Ocean View Hotel offers free Wi-Fi in every room and free parking for all guests. ❷ Breakfast is served daily from 6:30 to 10:00 for an extra charge. ❸ Airport shuttles run every hour.

What is NOT free for guests?

(A) Parking

(B) Breakfast

答えを見る答え (B)
www.oceanviewhotel.com

❶ Ocean View Hotel offers free Wi-Fi in every room and free parking for all guests. ❷ Breakfast is served daily from 6:30 to 10:00 for an extra charge. ❸ Airport shuttles run every hour.

答えと根拠

❷「Breakfast is served ... for an extra charge(朝食は追加料金)」なので、無料ではないのは (B)。

ワナの選択肢

(A) の駐車場は❶で free parking(無料駐車場)と書かれています。
NOT問題では、本文に「ある」ものがワナです。

解き方のコツ

extra charge / additional fee / for a fee はどれも「有料」のサイン。
NOT問題は選択肢を1つずつ本文で探して、見つかったものを消そう。

全文の和訳

www.oceanviewhotel.com
❶オーシャン・ビュー・ホテルでは、全室で無料Wi-Fi、全宿泊客に無料駐車場をご用意しています。❷朝食は毎日6時30分から10時まで、追加料金でご提供します。❸空港シャトルは1時間おきに運行しています。

設問:宿泊客にとって無料でないものは何ですか。

(A) 駐車場

(B) 朝食

この問題の単語

offer … 提供する

guest … 宿泊客

serve … (食事を)出す

daily … 毎日

extra charge … 追加料金

run … 運行する
