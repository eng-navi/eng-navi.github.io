The evidence supported (  ) hypothesis, so the researchers remained skeptical.

正解:① neither

The evidence supported neither hypothesis, so the researchers remained skeptical.

訳その証拠はどちらの仮説も裏付けなかったので、研究者たちは懐疑的なままだった。

代名詞 「研究者たちは懐疑的なままだった」から、証拠は仮説を裏付けなかったとわかります。 neither＋単数名詞で「どちらの〜も…ない」。either of の後ろには the hypotheses のように the＋複数名詞が必要です。 したがって、①neither が正解。
